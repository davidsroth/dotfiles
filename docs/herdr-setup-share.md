# My Herdr setup (for someone starting out)

Herdr is a persistent terminal workspace manager: one workspace per project, tabs for layouts, panes for shells/agents, and a sidebar showing which agents are working, blocked, or done. I'm a longtime tmux user; the combination of a real terminal multiplexer, text config, and agent-aware navigation is what sold me. The [official first-run guide](https://herdr.dev/agent-guide.md) is a better place to start than copying my config wholesale.

## Start small

1. Install Herdr using the [official install instructions](https://herdr.dev/docs/install/), `cd` into a repo, and run `herdr` from a normal terminal. Start your agent in the pane. Herdr can detect supported agents; `herdr integration install claude` or `herdr integration install pi` adds the corresponding integration when applicable. Check with `herdr integration status`.
2. Try the mouse first: click panes, drag splits, and use the sidebar. Default prefix is `Ctrl-b`; `prefix+?` displays the **active** keymap. Detach or close the terminal and reattach with `herdr`—the background server owns the running panes.
3. Keep the config incremental: `~/.config/herdr/config.toml` is optional, `herdr --default-config` prints defaults, and `herdr server reload-config` applies edits. My [full config.toml](https://github.com/davidsroth/dotfiles/blob/main/core/.config/herdr/config.toml) is a reference, **not a drop-in starter**: it disables onboarding, changes the prefix to `Ctrl-g`, and references local scripts, plugins, sound files, and Pi customization. Some modifier shortcuts may require terminal support. It requires Herdr 0.8.0+ for one local plugin.

## The bits I actually reach for

- **Workspace vs tab:** a workspace is a project; a tab is a layout within it. I bind `prefix+s` to a [workspace picker](https://github.com/davidsroth/dotfiles/blob/main/core/.config/herdr/bin/workspace-picker.sh) that lists existing workspaces plus [zoxide](https://github.com/ajeetdsouza/zoxide) directories through [fzf](https://github.com/junegunn/fzf). Pick a directory to create/focus its workspace. Requires Bash, Python 3, fzf, and zoxide; otherwise use Herdr's built-in workspace picker and CLI.
- **Find the right agent:** Herdr's `goto` picker is searchable and filters by state; mine is on `prefix+a`. `Alt-1..9` focuses sidebar agent rows. My [non-idle-agent switcher](https://github.com/davidsroth/dotfiles/tree/main/core/.config/herdr/plugins/non-idle-agent) puts “prefer done, then cycle other non-idle agents” on `Ctrl-s`, falling back to recent idle sessions. This is a local plugin, not built in; use the default picker before adopting it.
- **tmux-ish keys:** my prefix is `Ctrl-g`; `prefix+c` opens a tab, `prefix+hjkl` moves between panes, `prefix+z` zooms, `prefix+g` opens lazygit, and `prefix+v` opens scratch Neovim. Key names and actual actions are in the [config](https://github.com/davidsroth/dotfiles/blob/main/core/.config/herdr/config.toml). Herdr accepts only one key after the prefix, so tmux's nested key tables do not port directly.
- **Neovim ↔ pane navigation:** [this Neovim mapping](https://github.com/davidsroth/dotfiles/blob/main/core/.config/nvim/after/plugin/herdr_nav.lua) lets `Ctrl-h/j/k/l` cross a Neovim split boundary into a Herdr pane; the Herdr side uses [vim-herdr-navigation](https://github.com/paulbkim-dev/vim-herdr-navigation). Plain `prefix+hjkl` remains useful when another TUI intercepts Ctrl chords.
- **Tab labels:** a small [zsh preexec/precmd hook](https://github.com/davidsroth/dotfiles/blob/main/core/.config/shell/functions.sh#L925-L938) renames a tab to the running command and back to the shell. Trade-off: it overwrites manual tab names at the next prompt.

## Advanced / avoid copying blindly

- I use the preview update channel and a locally reviewed **version-specific patch** to the Pi integration for richer session state. Neither is necessary to try Herdr; the [patch notes](https://github.com/davidsroth/dotfiles/blob/main/core/.config/herdr/patches/README.md) are for people deliberately maintaining that exact integration version, not a generic install recipe.
- I have a [session-guard plugin](https://github.com/davidsroth/dotfiles/tree/main/core/.config/herdr/plugins/session-guard) and [safe-stop wrapper](https://github.com/davidsroth/dotfiles/blob/main/core/.config/herdr/bin/herdr-safe-stop.sh) because I observed Pi session references get lost during a reboot shutdown sequence. A detached client is **not** a stopped server; don't assume forcibly stopping the server preserves every agent's resume metadata. The guard's runtime snapshots contain local paths/session identifiers—**do not share** `~/.config/herdr/session.json`, `plugins.json`, logs, sockets, or `sessions/`.
- My `just herdr-setup` recipe is specific to my dotfiles checkout and my reviewed Pi patch; it is not a one-command installer for someone else's machine. Cherry-pick the small pieces you like and test them locally.
